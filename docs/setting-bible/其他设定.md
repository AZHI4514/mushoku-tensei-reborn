无职转生 · 其他设定
│
├─ 世界架构
│  ├─ 六面世界：六面体结构，各面为人的世界、魔的世界、龙的世界、兽的世界、海的世界、天的世界，中央空洞为“无之世界”
│  ├─ 人的世界：唯一残存的世界。原本为人族居所，其他世界崩坏后各种族逃入，形成六界融合的状态。一切存在皆持有魔力
│  └─ 无之世界：六面世界中心部的纯白空间，召唤/转移魔术的通道
│
├─ 核心能量
│  └─ 魔力
│     ├─ 六面世界一切存在皆持有，是魔术的能量源
│     ├─ 可使人/物获得特殊能力、使动植物魔物化、引发异常气象
│     └─ 世界总魔力量遵循能量守恒：魔力大幅减少时，世界会吸取物/生物转化为魔力以平衡
│
├─ 历法
│  └─ 甲龙历：为赞颂甲龙王佩尔吉乌斯而使用的历法，物语开始时为甲龙历407年
│
├─ 历史事件（按时间顺序）
│  ├─ 人魔大戦（约6000～7000年前）
│  │  └─ 魔界大帝奇希莉卡与五大魔王率魔族挑战人族，持续约千年，最终勇者亚尔斯击败魔王方，魔族沦为奴隶
│  ├─ 第二次人魔大戦（约5000～4200年前）
│  │  ├─ 奇希莉卡复活，率魔族联合兽族、海族再度挑战人族。人神暗中利用魔族意图杀魔龙王拉普拉斯
│  │  ├─ 魔龙王拉普拉斯独自击溃魔族军，后在与斗神铠之战中受致命伤死亡
│  │  └─ 死亡时转生法魔力暴走，巨大陆被炸开，中央大陆与魔大陆分离，空洞形成林古斯海；战后转移魔术被指定为禁术
│  └─ 拉普拉斯戦役（约500～400年前）
│     ├─ 魔神拉普拉斯统合魔族，联合海族/兽族向人族开战
│     ├─ 在中央大陆山脉放赤龙阻断交通，百年间除阿斯拉王国与米里斯神圣国外国人族国家全灭
│     └─ 七英雄说服海族/兽族加入人族方，最终击败魔神拉普拉斯
│
├─ 特殊能力/技术
│  ├─ 闘気
│  │  └─ 以魔力覆盖身体每一块肉片，爆发性提升身体能力。无需特别训练，锻炼身体即可自然掌握，但无才能者无法习得
│  ├─ 龍聖闘気
│  │  └─ 龙神乌尔佩独创的龙神流最大奥义，防御力被剑神加尔·法利昂称为“犯规级别”。除剑神流“光之太刀”外，其他攻击无法伤其分毫
│  ├─ 呪い
│  │  ├─ 魔力异常产生的特殊能力
│  │  ├─ 有益能力者称“神子”，不利益者称“呪子”，本质无区别
│  │  └─ 分先天性与迷宫后天获得两种
│  └─ 魔眼
│     ├─ 具有特殊能力的眼。无法控制魔力者会时刻处于发动状态，需戴眼罩
│     ├─ 魔力眼：可直视魔力，最常见魔眼，约万人中有一人持有
│     ├─ 識別眼：可看穿对象详细情报，情报基于魔界大帝奇希莉卡的知识
│     ├─ 透視眼：可透视无生物，魔力浓密处无法透视
│     ├─ 千里眼：可如望远镜般远视
│     ├─ 予見眼：可看见数瞬后的未来
│     ├─ 吸魔眼：可吸取魔力
│     └─ 万里眼：可看见世界任何地点。上位魔眼，奇希莉卡完全体时可赋予他人
│
├─ 诅咒/神子能力（按能力名/称号列出）
│  ├─ 诅咒（呪子侧）
│  │  ├─ 恐惧传染：使他人本能感到恐惧。拉普拉斯经由恶魔之枪转移给斯佩路德族，绿发为诅咒关键
│  │  ├─ 被厌恶/恐惧：使世间一切生物本能厌恶、恐惧、排斥持有者。根源为初代龙神所施术式的副作用之一
│  │  ├─ 难以被认知：他人极难记住持有者的脸，除生母外几乎无法识别。斯佩路德族因第三只眼可识别
│  │  └─ 魔力积聚（迷宫后天型）：体内魔力不断积聚，需通过性行为使魔力结晶化排出，否则致死
│  │
│  └─ 神子（神子侧）
│     ├─ 怪力之神子：天生身体异常强壮，力量足以与魔王抗衡，但极易破坏物品
│     ├─ 记忆之神子：与对方对视即可读取其记忆。米里斯教团将持有者作为工具使用，剥夺本名
│     ├─ 再生之神子：可回溯物体时间，目前表现为将物体状态倒退一天。真实能力涉及过去改写的可能性
│     ├─ 无力的神子：可无效化其他神子或呪子的能力。因过于危险，通常很早就会被杀
│     ├─ 信赖（人神系）：被所有人本能信赖，可在梦中与人对话并读取对方内心
│     ├─ 读心（迷宫后天型）：可读取他人思考，但因持有者心神丧失，读取不准确，缺失部分会自行补全
│     ├─ 幻境（冥王系）：可读取敌人记忆、预测其可能未来，并与对方欲望融合使其陷入幻境；也可通过分裂自身寄宿他人来同时控制多人
│     ├─ 魔眼赋予：可生产、控制并赋予他人魔眼。持有者体内携带12种魔眼，各自具有不同能力
│     └─ 悲鸣冲击波：发出悲鸣时产生冲击波，将对手吹飞
│
├─ 固有魔术/特殊魔术
│  ├─ 吠魔術/声の魔術：多尔迪亚族固有，以魔力乘声探查敌位/夺平衡
│  ├─ 乱魔：龙神乌尔佩独创，以对应魔力冲散发动前魔术
│  ├─ 転生法：初代龙神独创，将灵魂送入未来适配容器中复活
│  ├─ 龍門：甲龙王佩尔吉乌斯开发的召唤魔术。前龙门吸收魔力，后龙门将吸收的魔力转为己用
│  ├─ ペルギウスの使い魔：使役高智能强力精灵数百年，死亡后可在空中城塞复活
│  ├─ 重力魔術：王龙使用的固有魔术，可操纵重力
│  ├─ 占命魔術：以注魔水晶映出的未来与情报推演占卜
│  └─ 死霊魔術：苏生死者并使役。人魔大战时魔族使用，战后成为禁术并失传
│
├─ 魔术发动方式
│  ├─ 詠唱魔術：主流方式。通过咏唱自动完成术的生成→尺寸设定→射出速度设定→发动
│  └─ 無詠唱魔術：传统无咏唱需反复练习缩短咏唱至身体记忆。鲁迪式无咏唱则靠自身魔力控制完成全流程
│
├─ 魔道具
│  ├─ 魔道具：刻有魔法阵的道具，使用者以咏唱励起魔法阵使魔力流通发动
│  ├─ 自動人形：内部叠写魔法阵实现精密动作的人偶魔道具
│  ├─ ザリフの義手：解析自动人形制成的手部魔道具，通魔力即可按意志动作
│  ├─ ザリフの篭手：义手的笼手版，性能相同但消除穿戴违和感
│  └─ 魔導鎧：以义手技术制成的全身铠魔道具。一式高约3米，二式小型低耗魔
│
└─ 组织/势力
   ├─ 七大列強：世界最强七人排行榜。称号：技神、龙神、斗神、魔神、死神、剑神、北神
   ├─ 黒狼の牙：保罗率领的传奇冒险者队伍，已解散
   └─ デッドエンド：鲁迪、艾莉丝、瑞杰路德在魔大陆结成的冒险者队伍
