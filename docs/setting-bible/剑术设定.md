无职转生 · 剑术流派/等级/技能（Fandom + 日文维基合并版）
│
├─ 通用等级体系（三大流派共用框架）
│  └─ 初级 → 中级 → 上级 → 圣级 → 王级 → 帝级 → 神级
│     （北神流称号：初级→中级→上级→北圣→北王→北帝→北神）
│
├─ 剑神流（攻击特化，速度至上）
│  ├─ 定位：口号为“先手必胜”，以比对手先砍中为目标，攻击即最大防御[citation:7]
│  ├─ 称号：剑圣 → 剑王 → 剑帝 → 剑神（同一时期仅一位剑神，剑帝及以下可多人）[citation:7]
│  ├─ 架势：中段架势（基础）、上段架势（进攻）、拔刀架势（防守反击）[citation:7]
│  └─ 技能
│     ├─ 光之太刀（奥义）：剑圣资格方可传授，修至巅峰剑锋达光速，剑神流以此技称霸数百年[citation:7]
│     ├─ 光返（奥义）：对光之太刀的反击技，在对手加速完成前斩其手腕[citation:7]
│     ├─ 无音之太刀（上级技）：光之太刀下位技，斩击速度超音速且无声[citation:7]
│     ├─ **断臂（基础技）**：瞄准对手前臂斩断，或破坏其手臂骨骼使其无法用该手执剑[citation:7]
│     ├─ **湖面长刀**：有名称但详情不明[citation:7]
│     └─ **新月长刀**：Fandom 列出名称但详情未展开[citation:7]
│
├─ 水神流（防御特化，架招与反击）
│  ├─ 定位：以静制动，擅长应对任何攻击（含魔术与飞行道具），宫廷骑士/护卫主修[citation:2]
│  ├─ 称号：水圣 → 水王 → 水帝 → 水神（同一时期仅一位水神）[citation:12]
│  ├─ 克制关系（Fandom 补充）：对剑神流占优（专精迎击）；对北神流不利（北神流奇招难以预判）[citation:2]
│  └─ 技能
│     ├─ 流（基础/核心）：一切水神流技法的根基，架开敌剑并转移力量使对手失衡。虽为“基础”，但被视为流派最重要技法之一[citation:2]
│     ├─ 剥夺剑界（第六奥义）：现任水神将五奥义中最难的两式组合而成，摆出架势后可将四面八方进入范围的对手尽数斩切[citation:12]
│     └─ （初代水神留下的“五奥义”中，除被用于组合的两式外，其余具体名称在可查资料中仍未列出）
│
├─ 北神流（实战特化，无固定形式）
│  ├─ 定位：比起剑术本身，更重视“生存之道”与临机应变。无固定技法，每个修习者战斗方式各异[citation:3][citation:9]
│  ├─ 称号：北圣 → 北王 → 北帝 → 北神（历史上可同时存在多位北神）
│  ├─ 流派特点（Fandom 补充）：包含创伤应急处置、身体部位缺损仍能战斗的实战技术，受佣兵/冒险者青睐[citation:3]
│  ├─ 克制关系：对水神流占优（奇招难以架招）；对剑神流不利（剑神流以速度碾压，不给取巧空间）[citation:3][citation:9]
│  └─ 技能
│     ├─ 掷剑：二刀流架式反手投剑，狙击或撤退牵制
│     ├─ 四足之型：趴地以单手和口咬剑，四足爬行攻击
│     ├─ 胧十文字（奥义）：二刀流攻击被挡瞬间弃剑，从腰间拔第三把剑刺入防御空隙
│     ├─ 二十重拔刀（秘技）：极速拔刀术，右手拔刀时剑鞘左移，斩后纳刀
│     ├─ 重力破断（最强必杀）：北神三世使用，借王龙剑重力操作使对手浮空，再以大上段一击终结
│     └─ 不治伤北神流（幻之始祖剑术）：初代北神击败不死魔王所用，模仿其“技术”而非“生存之道”，无人得见全貌
│
└─ 混用/跨流派
   └─ 保罗·格雷拉特：三大流派均达上级，但未专精一派（北神流 Fandom 页面将其列为 Advanced User）[citation:9]
