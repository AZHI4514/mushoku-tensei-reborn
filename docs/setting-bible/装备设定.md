无职转生 · 装备（游戏视角·按栏位分类）
│
├─ 【全身装甲 · 魔导铠系列】
│  │  以“扎里夫的义手”技术为基础开发的全身铠魔道具，核心功能是大幅提升穿戴者的身体能力，但消耗巨量魔力。
│  │
│  ├─ 零式
│  │  └─ 一式的前置试作型。深蓝色涂装，出力高于一式，但魔力效率最差，续航极短。左手岩炮弹散弹枪，右手岩炮弹格林机枪，拳端装备保罗的破甲短剑。
│  │
│  ├─ 一式
│  │  └─ 为与龙神奥尔斯帝德战斗而制作的试作型。全高约3米，迷彩涂装，极笨重。防御力与机动力达七大列强下位水准，但魔力消耗极大，除鲁迪外无人能驾驭。右手帝级岩炮弹格林机枪（每秒10发），左手掌吸魔石，另装备破甲短剑盾。
│  │
│  ├─ 二式改
│  │  └─ 以一式为原型小型化、低耗魔化的版本。漆黑色，性能降至圣级剑士水准，但可长时间穿在长袍下。右手岩炮弹散弹枪（同时10发），左手吸魔石。背部追加洛琪希开发的“卷轴推进器”，可紧急召唤一式。
│  │
│  ├─ 三式
│  │  └─ 鲁迪晚年使用的完成型。全高约2米，兼具一式同等性能与小型化，是后世泛用魔导铠的原型。
│  │
│  └─ 泛用魔导铠
│     └─ 鲁迪逝世后由三女莉莉开发。以三式为原型改良，让鲁迪以外的人也能使用，用于降低大型魔物讨伐风险。
│
├─ 【武器 · 剑】
│  │
│  ├─ 无铭
│  │  └─ 魔界名匠尤里安·哈利斯科作品。刀长约60cm的弯刀。洛琪希之父赠予鲁迪一行作防身用，由艾莉丝持有多年。
│  │
│  ├─ 指折
│  │  └─ 尤里安·哈利斯科以王龙王卡夏库特为材料制作的四十八把魔剑之一。装饰华丽的短剑，价值十万阿斯拉金币。鲁迪转交给艾莉丝使用。
│  │
│  ├─ 平宗
│  │  └─ 四十八把魔剑之一。剑刃散发不祥红色光辉。现任剑神七剑之一，授予基列奴作为剑王证明。
│  │
│  ├─ 喉笛
│  │  └─ 四十八把魔剑之一。现任剑神七剑之一。
│  │
│  ├─ 凤雅龙剑
│  │  └─ 龙皇授予初代剑神的魔剑，单刃微弧。锤炼入刀身的魔力可无视对手斗气防御。艾莉丝成为剑王时获授，曾用以斩断龙神手腕，于斗神一战折断损毁。
│  │
│  └─ 王龙剑卡夏库特
│     └─ 尤里安·哈利斯科最高杰作，世上最强之剑。四十八把魔剑均为打造此剑的练习作。具有重力操作能力，持剑者可使用重力魔术，使斩击附加重力、获得无视惯性的回避、并使对手浮空。后与斗神铠一同被封印于地龙谷底。
│
├─ 【武器 · 其他】
│  │
│  └─ 恶魔之枪
│     └─ 拉普拉斯赠予斯佩路德族的魔道具三叉枪。大幅强化持有者身体能力、无效化人族魔术、进一步强化斯佩路德族本已敏锐的感官，但会缓慢侵蚀使用者精神。瑞杰路德持有。
│
├─ 【防具/饰品 · 魔力附加品】
│  │  注：魔力附加品是迷宫遗品等自然获得魔力的物品，效果随机且无法人工制造。
│  │
│  ├─ 烦热斗篷
│  │  └─ 将使用者体温维持在一定温度的斗篷。希露菲与卢克使用。
│  │
│  ├─ 疾风之靴
│  │  └─ 以通常数倍速度奔跑的鞋子。希露菲使用。
│  │
│  ├─ 压倒的手套
│  │  └─ 将手掌所受冲击减半的手套。希露菲使用。
│  │
│  ├─ 钢线蚕胸衣
│  │  └─ 以抵抗大部分刀刃的纤维制成，可防投掷匕首级别的伤害，但无法抵挡剑神流剑技。希露菲使用。
│  │
│  ├─ 救赎者墨镜
│  │  └─ 隐藏面容的同时，可即时感知王女的危机状态。希露菲以守护术师身份佩戴，获国王特别许可。
│  │
│  └─ 幻影戒指
│  │  └─ 可将佩戴者外观变为戒指另一只佩戴者的样子（不改变瞳色与声音）。希露菲使用。
│
├─ 【魔道具 · 可装备/携带】
│  │
│  ├─ 岩炮弹格林机枪
│  │  └─ 十根魔杖捆束、解除魔力输出限制的魔道具。可连发万发以上帝级威力的岩炮弹。原为对抗“乱魔”而研发，装备于魔导铠右手。
│  │
│  ├─ 岩炮弹散弹枪
│  │  └─ 格林机枪的改良版，将连续发射的时间差压缩为同时发射十发。装备于魔导铠左手。
│  │
│  ├─ 卷轴推进器
│  │  └─ 洛琪希制作，书包大小的魔道具，内置十张卷轴。按腰部按钮注入魔力即可直接发动卷轴内魔法阵，用于紧急召唤魔导铠一式。装备于二式改背部。
│  │
│  ├─ 前龙门
│  │  └─ 雕刻龙形的白银色门状魔道具。可吸收敌方魔力、无效化魔术、拭去斗气。普通战士数分钟内即被吸尽魔力昏厥。
│  │
│  ├─ 后龙门
│  │  └─ 黄金色门状魔道具。可使用前龙门吸收的魔力，用于抑制战斗中的魔力消耗，但不回复使用者自身魔力。
│  │
│  ├─ 通信石版
│  │  └─ 文字通信石板。主版所写内容会显示在副版上，双方各持主副两版即可远程通信。奥尔斯帝德与爱丽儿持有。
│  │
│  └─ 冒险者卡
│     └─ 冒险者身份证明卡，龙族制作的魔道具。可用手指按住中央并说出语言来切换显示文字。

│     ├─ 来源：10岁生日时由伯雷亚斯家（艾莉丝一方）赠送

└─ 【特殊 · 非一般装备】
   │
   ├─ 斗神铠
   │  └─ 第二代龙神拉普拉斯制作的最高杰作兼最失败作品。穿戴者可获得极高战力，但铠甲会吸取穿戴者生命，故被封印。后被人神怂恿取出，与拉普拉斯死战，导致大陆分裂、林古斯海形成。最终与王龙剑一同封印于地龙谷底。
   │
   └─ 扎里夫的义手 / 笼手
      └─ 解析自动人形制成的手部魔道具。通魔力即可按意志动作，力量与魔力量成正比，可再现指尖触感。扎诺巴曾用于抑制怪力，后让给失去左手的鲁迪。笼手版消除了穿戴违和感。
