# 切片 1f · 施法的手臂动作实施计划

2026-11-25 · 已完成。交付目标是让施法者和旁观者都看到右臂平举、左手搭右腕，咏唱水花与水弹从当时的右掌中心出现。[切片规格](../specs/2026-11-25-slice-1f-casting-arm-pose.md)

## Global Constraints

- 使用 Java 21、Minecraft 1.21.1、NeoForge 21.1.267、ModDevGradle 2.0.148、Gradle Wrapper 9.2.1、GeckoLib 4.7.7。Windows 使用 `./gradlew.bat`。
- 服务端裁决开始、中断和完成。客户端根据现有 `chant_state` 展示动作。抬手的 5 tick 包含在 100 tick 咏唱内，完成或松键后用 5 tick 收势。完成扣 1 点魔力，中断保留魔力。
- 左右主手均由右掌施法，右肩至右腕在搭腕阶段与地平线平行。持物按原版主副手分配到实际握持侧。准星控制弹道，起点取右臂末端面中心。
- 姿态进度与几何计算归入 `magic/core`，世界坐标适配归入 `magic/runtime`，模型、相机和手持物绘制限客户端。保留 1e 的准星、近距过渡及眼到手遮挡规则。[1e 规格](../specs/2026-11-21-slice-1e-anchor.md)

## 验收任务

A 操作施法者，B 使用独立客户端旁观。任务 10–13 每组分别使用左主手和右主手。复用同一测试场地、靶面及 1e 开发采样开关 `-I dev/anchor/sampling.gradle -PanchorSamples=true`。各项保留最差样本对应的日志或画面。
