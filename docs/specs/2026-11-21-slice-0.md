# 2026-11-21 切片 0 · 项目骨架规格

本片交付一个可打包的 Minecraft 1.21.1 NeoForge 模组。公共入口位于 com.azhi.mushoku.Mushoku，模组 ID 为 mushoku_tensei_reborn。入口在模组事件总线上挂接空的物品 DeferredRegister，内容条目数为零。魔力与施法由切片 1 定义。

## 验收

- Temurin Java 21 配合仓库自带的 Gradle Wrapper 和 ModDevGradle 完成 build。
- build/libs 下的 JAR 包含入口类、注册表类及 META-INF/neoforge.mods.toml，元数据声明 Minecraft 和 NeoForge 依赖。
- 提供 runClient、runServer 和 runData 开发任务。生成资源进入主资源集。
- 在项目根目录执行 python tests/contracts.py，退出码为 0。
