# VISION — mushoku_tensei_reborn

> 状态：provisional。记录方向，不是锁定规格。宪法层，一次写成，方向变化才修。

## 核心命题

原作里鲁迪最强的不是魔力总量，而是**他理解魔术**——他把魔术从「天赋」
变成「可拆解、可优化、可超越」的东西。别人咏唱十秒，他压缩到五秒；别人
按等级用术，他往初级术里灌魔力打出帝级威力。

> **本 mod 要让玩家经历同一条曲线：从照本宣科，到理解，到超越。**

## 差异化：不做「法术大礼包」

市面上的魔术 mod 大多是加几十个法术 + 一根魔力条。本 mod 的赌注不同：

- 成长发生在**理解**上，不在等级上：缩短咏唱 → 省略咏唱 → 无咏唱，
  每一步都是玩家对系统理解的加深，不是数值变大。
- **越级**是核心奖励：低级术灌入大量魔力可打出远超其等级的威力。
  这奖励的是「资源调度」，不是「解锁新东西」。
- **混合**是第二层深度：水+土=泥沼、水+水+土=浓雾。一个玩家能记住的
  组合空间，比一百个孤立法术更有趣。

## 玩家节奏（愿景态）

1. 起步：拿到第一根魔杖，学会第一个初级术（水弹/火球/石弹之一）。
2. 熟练：缩短咏唱，把十秒压到五秒；学会同一属性的更多术。
3. 跨系：掌握第二、第三属性，发现混合的可能。
4. 省略咏唱：不再依赖完整咏唱，开始能在移动中施法。
5. 无咏唱：彻底跳过咏唱流程，只剩魔力与想象力。
6. 越级：主动往低级术灌魔力，用初级术打出上级效果，代价是魔力见底。
7. 魔法阵：召唤、结界、转移——需要预先布置的重型魔术。

## 这个 mod 不是什么

- 不是法术数量竞赛（数量是副产品，不是目标）。
- 不是技能树 UI（进度必须发生在世界里，不是菜单里）。
- 不是原作剧情复刻（世界观取骨架，不还原剧情与角色）。
- 不是战斗 mod（第一模块只做魔术本身，战斗体系是后续独立模块）。
- 不是数值膨胀器（更大的火球不是奖励，「能到达哪里」才是）。

## 什么算好（品味裁决用）

- 一个法术让人改变行动路线，而不是循环里多按一个键。
- 失败可学习：玩家失败后知道「下次该多灌点魔力」而不是「运气不好」。
- 成长可观察：别的玩家看得出「这个人在练魔术」，而不是「这个人等级高」。
- 抄设定抄得准：七级体系、四属性、咏唱三阶段，与原作一致。
