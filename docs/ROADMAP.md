## 设定文件去向（切分依据）

| 设定文件 | 交给哪层 | 说明 |
|---|---|---|
| 魔术设定.md | **魔术模块**（核心） | 等级/属性/咏唱/法术表，是本项目第一模块的直接来源 |
| 其他设定.md | **魔术模块** + 后续 | 魔力体系、咏唱发动方式 → 魔术；斗气/魔眼/诅咒 → 战斗；世界架构 → 设定背景 |
| 装备设定.md | 装备模块 | 魔导铠/魔剑/魔力附加品/魔杖。魔杖在装备模块提供施法加成 |
| 剑术设定.md | 战斗模块 | 三大流派与等级，与魔术模块无实现耦合 |
| 种族设定.md | 种族模块 | 影响玩家可选项与生物分类 |
| 魔物设定.md | 魔物模块 | 实体设计来源 |
| 地图设定.md | 世界模块 | 维度/生物群系/结构来源 |

**设定集原文**保存在 `docs/setting-bible/`，不改、不删、不进必读链。
需要「原作怎么写的」时才查；要落地成玩法，结论写进模块文档。

## 魔术模块切片路线

```
切片0  项目骨架：Gradle + @Mod + 空 registry + contracts 跑通
切片1a 魔力（DataAttachment）
切片1b 徒手咏唱（R 键、服务端判定、完成扣魔力）
切片1c 水弹弹体
切片1d 3D 动画弹体（GeckoLib）
切片2  等级矩阵：7 级 × 4 属性表 + 熟练度 + 多法术
切片3  咏唱缩短 → 省略咏唱（成长曲线第一段）
切片4  混合魔术：水+土 → 泥沼（验证组合机制）
切片5  越级注入：低级术灌魔力打出上级威力 + 反噬代价
后续   无咏唱 / 魔法阵 / 召唤结界
```

每片一个 `docs/specs/YYYY-MM-DD-*.md` + `docs/plans/YYYY-MM-DD-*.md`。

## 明确不做（至少第一版）

- 神级术（大陆规模改写）——与 MC 世界尺度不兼容，做成剧情级不可操作内容。
- 转移/过去转移魔术——传送本身破坏探索体验，且原作中即为禁术。
- 死灵魔术——已失传设定，实现成本高收益低。
